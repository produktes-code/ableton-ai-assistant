# Antigravity V2.0.0 - User Manual

## Introducción
Bienvenido a Antigravity V2.0.0, la herramienta IA definitiva para Ableton Live. 
Esta versión incluye el nuevo motor Anti-Clash, la arquitectura de red Thread-Safe, UI Glassmorphism y MIDI Generator V2.

## Características Principales
1. **Motor Anti-Clash Aislado**: Procesamiento DSP en tiempo real en subproceso de 50ms sin impactar a Ableton.
2. **Glassmorphism UI**: Interfaz oscura translúcida optimizada.
3. **MIDI Generator V2**: Soporte de ritmos y escalas humanizados.
4. **Seguridad Total TCP**: Tokens únicos por sesión, backpressure.

## Instalación
1. Copia `remote-script/AntigravityCore` a tu carpeta de Scripts MIDI de Ableton.
2. Inicia Ableton y selecciona `AntigravityCore`.
3. Inicia la aplicación Electron ejecutando `npm start` en la carpeta `electron-app`.
